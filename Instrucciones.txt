## Requisitos previos
- **Python:** Versión 3.11

Para desarrollo:
copiar el repositiorio de git
1. Abrir una terminal en la carpeta donde se van a querer guardar los archivos

2. Escribir
	git config --global user.name Dressappadmin
	git config --global user.email dressappadmin@gmail.com
	git init
	git remote add origin https://github.com/Dressappadmin/tfm.git
	git pull origin main
	git branch develop_nombre

3. Con esto tendremos los archivos que están en la rama main en nuestro local. 
Trabajamos cada uno en su rama develop para facilitar la organización 

para ponerlo a funcionar:
1. Abrimos VSCode y abrimos la carpeta de los archivos

2. Creamos nuestro entorno virtual. Abrimos una terminal de VSCode en la carpeta del código y escribimos
	python -m venv venv

Nos dará a elegir la versión de python. Elegimos la 3.11.9. Si no la tenemos hay que descargarla

3. Activamos el entorno virtual
En widnows (powershell)
	.\venv\Scripts\Activate.ps1
En MAC 
	source venv/bin/activate

4. hacemos CTRL + MAYUS + P y buscamos seleccionar el interpreter de python. Elegimos el de venv/bin/python

5. Abrimos una terminal de VSCode y ejecutamos
	pip install -r requirements.txt

Para construir y subir el docker a google cloud. Cambiar el 7 por la versión que toque

1. Asegúrate de haber guardado todos los archivos

2. Abrir la terminar. Navegar a la carpeta raíz. Por ejemplo
	cd ruta/carpeta/tfm
	
3. Instalar las librerías de 'gcloud'. Esto cambia según el sistema operativo.
	En fedora: sudo dnf install gcloud
	
4. Iniciar sesión en google desde la terminal. Esto nos permite 'enlazar' nuestra terminal con los servidores de google para ejecutar ahí comandos, con el prefijo gcloud.
	gcloud auth login
	gcloud config set project dressapp-503311

5. Autenticarse
	gcloud auth print-access-token | sudo docker login -u oauth2accesstoken --password-stdin https://europe-southwest1-docker.pkg.dev

6. Construir el docker. Cambiar el 7 por la versión que toque.
	sudo docker build -t europe-southwest1-docker.pkg.dev/dressapp-503311/outfitai-repo/outfitai-app:v7 .

7. Hacer el push. Cambiar el 7 por la versión que toque.
	sudo docker push europe-southwest1-docker.pkg.dev/dressapp-503311/outfitai-repo/outfitai-app:v7

8. Ponerlo en marcha. Cambiar el 7 por la versión que toque.
	gcloud run deploy outfitai-api \
	  --image europe-southwest1-docker.pkg.dev/dressapp-503311/outfitai-repo/outfitai-app:v7 \
	  --region europe-southwest1 \
	  --set-env-vars SUPABASE_URL="tu_url_de_supabase",SUPABASE_KEY="tu_anon_key_de_supabase"

-----------------------------------------------------------------------------------
Para ver los logs (podemos cambiar el límite a nuestro antojo)
cloud run services logs read outfitai-api   --region europe-southwest1   --limit 60

Cuando se modifique el código, una vez guardado, si no es la primera vez que tenemos que iniciar sesión, podemos pegar directamente en la terminal los pasos 5 al 7 seguidos (cambiando el 7 a la versión que corresponda). Además no hace falta volver a pasar las variables de entorno:

gcloud auth print-access-token | sudo docker login -u oauth2accesstoken --password-stdin https://europe-southwest1-docker.pkg.dev
sudo docker build -t europe-southwest1-docker.pkg.dev/dressapp-503311/outfitai-repo/outfitai-app:v7 .
sudo docker push europe-southwest1-docker.pkg.dev/dressapp-503311/outfitai-repo/outfitai-app:v7
gcloud run deploy outfitai-api \
  --image europe-southwest1-docker.pkg.dev/dressapp-503311/outfitai-repo/outfitai-app:v7 \
  --region europe-southwest1
